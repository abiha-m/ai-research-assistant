## Week 2 Plan: AI Research Assistant (RAG)

### Goal
Build the core RAG pipeline: PDF ingestion, text chunking, embeddings, and semantic search.

### Daily Focus

**Day 8:** Learn PDF loading with PyPDFLoader
- Install PyPDF
- Load a sample PDF
- Extract text
- Test with a small PDF

**Day 9:** Text chunking and splitting
- Learn about chunk size and overlap
- Implement text splitting
- Test chunking on a sample PDF

**Day 10:** Generate embeddings with OpenAI
- Understand embeddings
- Generate embeddings for chunks
- Store embeddings in memory

**Day 11:** Set up Chroma vector database
- Install ChromaDB
- Store embeddings in Chroma
- Run a similarity search

**Day 12:** Build semantic search and retrieval
- Query the vector database
- Retrieve top chunks
- Display results

**Day 13:** Build question-answering with GPT
- Combine retrieval with GPT
- Answer questions based on retrieved chunks
- Test with sample questions

**Day 14:** Review and polish
- Test with multiple PDFs
- Fix any bugs
- Update documentation
- Reflect on progress
